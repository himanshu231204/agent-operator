# Phase 7 — Safety: Detailed Implementation Plan

**Branch**: `phase-7-safety`

## Goal

Harden the operator with in-flight task cancellation, per-task timeouts, in-process rate limiting, a secrets audit endpoint, and a CLI surface for approval workflows.

## Architecture / proposed approach

1. **In-flight cancellation**: Add a `cancelled_tasks: set[uuid.UUID]` to `Orchestrator` that `_check_limits` consults. The cancel endpoint adds to this set; the orchestrator checks it every iteration and transitions to `CANCELLED` + stops new tool calls.

2. **Per-task timeouts**: Add `timeout_seconds: int | None` to `Task` model. The orchestrator uses `min(task.timeout_seconds, limits.max_execution_seconds)` as the effective timeout. Exposed via `POST /tasks/{id}` request body and `POST /tasks/{id}/cancel`.

3. **Rate limiting**: Add a `RateLimiter` class (token bucket per tool name) in `app/policies/rate_limit.py`. The `ToolExecutionEngine` checks it before executing any tool. Configurable via `LIMITS_*` settings.

4. **Secrets audit**: Add `GET /audit/secrets` endpoint that scans recent `ToolCall` rows for patterns resembling secrets (API keys, tokens, passwords) in inputs/outputs. Returns findings without exposing the actual secret values.

5. **CLI surface**: Add a `cli/` package with a `ApprovalCLI` that polls for pending approvals and prompts the user to approve/reject. Uses the existing REST API.

## Risks, tradeoffs, and open questions

1. **In-flight cancellation granularity**: The orchestrator checks cancellation between steps, not mid-step. A single slow tool call (e.g., a 30-second LLM call) will still complete before cancellation takes effect. Acceptable for now; future work could use `asyncio.Task.cancel()`.

2. **Rate limiting scope**: Per-tool rate limiting is simple but may be too coarse. A single tool (e.g., `web_fetch`) hitting different domains should ideally have per-domain limits. Out of scope for Phase 7.

3. **Secrets audit false positives**: Pattern matching will flag any string matching `sk-*` or `gho_*`. The endpoint returns redacted previews, not full values, to avoid creating a new leakage vector.

4. **CLI transport**: The CLI uses HTTP to the running API. For local-only deployments, this is fine. For remote deployments, the CLI would need auth tokens. Out of scope for Phase 7.

5. **Migration**: Adding `timeout_seconds` column requires a migration. The column is nullable, so existing rows default to NULL (use global limit).
